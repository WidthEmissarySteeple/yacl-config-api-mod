# YetAnotherConfigLib — Modern Config API

[![Download Latest](https://img.shields.io/github/v/release/WidthEmissarySteeple/yacl-config-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/WidthEmissarySteeple/yacl-config-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A builder-based configuration library providing beautiful, accessible config screens for Fabric and Forge mods.

![YetAnotherConfigLib — Modern Config API Preview](https://cdn.modrinth.com/data/1eAoo2KR/images/5862570281f5109119c11f21a1bba52b6a2ab17f_350.webp)

## Features

- Builder API for constructing config screens in code
- Clean modern UI with search and per-option reset
- Supports primitives, enums, colors, and custom types
- Works on Fabric, NeoForge, and Forge loaders
- Used by Sodium, Iris, and many performance mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
